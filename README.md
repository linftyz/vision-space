# Vision Space

Lightweight native image viewer for macOS, built with Tauri 2, React, and Base UI.

[中文说明](README.zh.md)

## Features

- Open a single image or a folder
- Drag and drop local images
- Zoom, pan, rotate, and fit-to-window
- Bottom filmstrip for quick browsing
- Theme modes: system, light, dark
- Accent color customization

## Tech Stack

- Tauri 2
- React 19
- TypeScript
- Vite
- Tailwind CSS v4
- coss/ui on Base UI
- Zustand

## Development

```bash
pnpm install
pnpm dev
```

## Build

```bash
pnpm build
pnpm tauri build
```

## About

Vision Space is a fast, local-first image viewer designed for macOS now and Linux later.
